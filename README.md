Um jogo incremental (*idle/clicker*) com estética retro da Web 2.0 de 2006. O projeto combina arte em caracteres ASCII, interface minimalista sem CSS moderno/neon e todas as mecânicas clássicas de Cookie Clicker em um único arquivo HTML autocontido.

## 🎮 Funcionalidades

- [x] **Biscoito ASCII Interativo:** Clique no biscoito para gerar cookies e veja os pontos flutuantes em tempo real.
- [x] **Loja de Construções Retro:** Compre desde *Ponteiros ASCII* e *Vovós do Bloco de Notas* até *Prismas ASCII 2006*.
- [x] **Upgrades & Melhorias:** Desbloqueie melhorias que duplicam a produção ou aumentam o poder do clique.
- [x] **Sistema de Conquistas:** Desbloqueie insígnias por marcos de cliques, produção e eventos.
- [x] **Biscoitos Dourados Flutuantes:** Aparições aleatórias que concedem *Frenesi (CPS x7)*, *Sorte Instantânea* ou *Clique Frenético (Clique x777)*.
- [x] **Ascensão & Prestígio Celestial:** Reinicie seu progresso para ganhar **Chips ASCII**, garantindo um bônus permanente de CPS.
- [x] **Salvamento Local & Import/Export:** Progresso salvo automaticamente via `localStorage`, além de suporte a salvamento por código Base64.
- [x] **Modais ASCII Internos:** Modais estilizados em texto que substituem os popups padrão do navegador.

## 🚀 Como Executar Localmente

1. **Clone o repositório:**
   ```bash
   git clone https://github.com/seu-usuario/seu-repositorio.git
   ```

2. **Acesse a pasta do projeto:**
   ```bash
   cd seu-repositorio
   ```

3. **Abra o jogo:**
   - Dê um duplo clique no arquivo `index.html`, ou rode via terminal:
     - **Windows:** `start index.html`
     - **macOS:** `open index.html`
     - **Linux:** `xdg-open index.html`

## 🧰 Tecnologias

- **HTML5:** Estrutura e marcação semântica.
- **CSS3:** Estilização retro com fonte monoespaçada (`Courier New`) e bordas ASCII.
- **JavaScript (Vanilla ES6+):** Lógica do jogo, cálculo de delta-time (`Date.now()`), sanitização de dados e gerenciamento de estado.
- **Web Storage API (`localStorage`):** Persistência do save local no navegador.
